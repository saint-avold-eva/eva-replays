EVA MULTI PLAYER v0.3 — LECTEUR PUBLIC + ADMINISTRATION LOCALE

CONTENU
- index.html : lecteur public, sans fonction d'administration.
- videos.json : bibliothèque des replays publiée avec le lecteur.
- admin-local.html : outil d'administration à conserver sur TON ordinateur. NE PAS envoyer ce fichier sur GitHub.

MISE EN PLACE SUR GITHUB
1. Dans ton dépôt GitHub, remplace index.html par celui de cette version.
2. Remplace videos.json par ton fichier actuel contenant tes replays (ne repars pas du fichier vide fourni si tu as déjà des replays).
3. N'envoie PAS admin-local.html sur GitHub.
4. Valide les changements (Commit changes).

UTILISER L'ADMINISTRATION SUR TON PC
1. Place admin-local.html et videos.json dans le même dossier sur ton ordinateur.
2. Ouvre PowerShell dans ce dossier.
3. Lance : py -m http.server 8000
4. Ouvre : http://localhost:8000/admin-local.html
5. Ajoute/modifie/supprime tes enregistrements.
6. Clique sur « Exporter videos.json ».
7. Remplace ensuite videos.json dans ton dépôt GitHub par le fichier exporté, puis valide le changement.

UTILISER LE LECTEUR PUBLIC
Les clients utilisent uniquement l'adresse GitHub Pages habituelle. Ils peuvent consulter les replays, mais ne voient plus le bouton de gestion.

IMPORTANT
- L'administration est séparée du site public : admin-local.html reste sur ton PC.
- Ne publie jamais admin-local.html sur GitHub.
- Le lecteur public et videos.json restent accessibles publiquement.
- Les vidéos YouTube « non répertoriées » ne sont pas privées : toute personne ayant le lien peut les regarder.
- Si quelqu'un possède un accès en écriture à ton dépôt GitHub, il pourrait toujours modifier les fichiers ; protège donc ton compte GitHub avec un mot de passe fort et la double authentification.
